# CityCalls Help Now - Standalone Service App

Independent on-demand maid and cleaning service web application for CityCalls Help Now.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```
